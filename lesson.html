How to find duplicate files with a small Python tool

Short answer

To find duplicate files, compare what is inside them, not what they are called. Group files by size first, then fingerprint the files that share a size with hashlib.sha256. Files with the same fingerprint are almost certainly copies, and a byte-for-byte comparison confirms it. This lesson builds a tool that does both, only reports, and never deletes anything.

Common mistakes when cleaning duplicates

  1. Trusting file names. "copy" in a name proves nothing. Compare contents.
  2. Trusting size alone. Same size can still be a different file. The step with same-size-different.txt shows it.
  3. Deleting automatically. A tool cannot know which copy you want to keep.
  4. Skipping the backup. Copy anything important somewhere safe before you delete.
  5. Fixing the program to match a wrong test. Work the number out by hand first.

Frequently asked questions

How do I find duplicate files on Windows?

Compare contents, not names. A short Python script can group files by size, then fingerprint the ones that match with SHA-256. This lesson builds one that only reports and never deletes.

Is it safe to delete duplicate files?

Only after you check. Keep one copy you can find, and delete extras yourself. Back up first. This tool never deletes anything for you.

Why compare size before contents?

Files of different sizes cannot be identical, so comparing sizes first avoids reading most files.

What is a hash?

A short fingerprint made from a file's contents. Identical contents give the same hash, and one changed letter gives a very different one. A matching hash is very strong evidence, not proof, so the tool also compares the bytes.

Does the tool work on Mac and Linux?

The code does not depend on Windows, and it passed its tests on Windows and Ubuntu runners. See the notes on this page for what was tested.
